**StatCallout** — the huge-numeral proof point Hargrove leans on for credibility.

```jsx
<StatCallout value="$400B+" label="client assets across RIA partners" size={72} />
<StatCallout value="Top 5" label="Barron's RIA ranking, nine consecutive years" onNavy />
```

`value` is the big display numeral; `label` the muted caption. `size` 60–96 for hero use. `onNavy` for dark bands. Only extract stat callouts from source numbers — don't invent stats.
