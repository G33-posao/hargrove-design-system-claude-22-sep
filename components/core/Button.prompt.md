**Button** — Hargrove's full-pill button; use for primary CTAs ("Schedule a Consultation", "Partner With Us") and secondary actions.

```jsx
<Button variant="primary" size="lg" href="#">Schedule a Consultation</Button>
<Button variant="secondary">See How It Works</Button>
<Button variant="onNavy">Contact the legal team</Button>
```

Variants: `primary` (navy fill), `secondary` (navy outline), `onNavy` (white fill for dark backgrounds), `ghost`. Sizes: `sm` / `md` / `lg`. Hover darkens/lifts; never shrinks. Navy is the only accent — do not recolor.
