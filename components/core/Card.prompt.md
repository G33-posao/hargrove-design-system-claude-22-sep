**Card** — the base panel surface; wrap testimonials, commitments, pricing, and process steps.

```jsx
<Card>
  <h3>Fixed Price</h3>
  <p>One flat fee, known before the work begins.</p>
</Card>

<Card tone="navy">…highlighted tier / on-navy tile…</Card>
```

`tone`: `light` (#F8F8F8, default), `white`, `navy` (inverted). Set `interactive` to raise the shadow on hover. Radius 14px, 1px `#E3E7EE` border, soft navy shadow — never a colored left-border accent.
