# Social — LinkedIn card library

Seven standard 1200×1200 layouts from `../guidelines/social-linkedin.md` (client's LinkedIn Social Design Guidelines v1.0). Read that document before editing any of these.

| File | Layout | Surface |
| --- | --- | --- |
| `01-navy-statement.html` | Hook statement | Navy |
| `02-light-checklist.html` | Content + navy checkmark squares | White |
| `03-carousel-cover.html` | Carousel cover (wordmark bottom-left) | Navy |
| `04-event.html` | Event / webinar announcement + speaker | Navy |
| `05-stat.html` | Stat callout | Panel `#F8F8F8` |
| `06-quote.html` | Quote / testimonial | Panel `#F8F8F8` |
| `07-carousel-closing.html` | Carousel closing (CTA + URL, no arrow) | Navy |

## Frame (identical on every card)
1200×1200 canvas · 96px margins on all sides · wordmark SVG 210px wide (top-left; bottom-left on covers and closing cards) · gaps 28px eyebrow→headline, 44px headline→support · carousel arrow bottom-right, 3px stroke, on every slide except the last.

## Carousel rhythm
`03-carousel-cover` (navy) → `02` / `05` / `06` (light) → `07-carousel-closing` (navy). Max two background colors per carousel.

## Copy
All copy in these files is verbatim from approved Hargrove source (signature lines, canonical package inclusions, proof points, the Bob Glass testimonial). Replace with approved copy only — never write new marketing language.

**Note:** `06-quote.html` carries no headshot. Photos in `assets/people/` are Hargrove attorneys only — never attach one to an external advisor's quote.
